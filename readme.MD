# Membangun ETL pipeline sederhana

Membuat python automation untuk scraping dari website yang sudah disediakan oleh Dicoding

## Aktivasi Conda (Jika Memakai Anaconda dan memakai base env)

```bash
  conda activate base
```

## Cara Menjalankan skrip
```bash
  python3 -m main.py
```

## Menjalankan unit test pada folder tests

```bash
  python3 -m pytest tests
```

## Menjalankan test coverage pada folder tests

```bash
  python3 -m pytest --cov=utils tests/
```
